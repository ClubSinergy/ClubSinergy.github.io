Privacy Policy — YouTube Agent Leo

Last updated: 21 November 2026

YouTube Agent Leo is a personal tool. Its only user is the channel owner, Leonid Marchenko.

What data it uses

With the owner's permission (Google OAuth), the tool uses the YouTube Data API to upload the owner's own videos, set their titles, descriptions and privacy status, and add them to playlists on the owner's channel.

How data is stored

The access token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising.

YouTube Agent Leo's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

How to revoke access

Access can be revoked at any time at myaccount.google.com/permissions.
